InboxBridge for Linux
=====================

Quick start:

  1. Extract this archive
  2. Run: chmod +x install-linux.sh && ./install-linux.sh
  3. Close ALL Chrome/browser windows and reopen

Uninstall:

  rm ~/.local/bin/inboxbridge
  rm ~/.config/google-chrome/NativeMessagingHosts/com.inboxkey.bridge.json

Source code: https://github.com/slmnsrf/inboxkey
