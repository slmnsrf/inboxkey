Automation Level Indicators Ideation 2026-03-21

Design Decisions

    Automation Level Indicators

    Exploring different approaches for communicating the 4 automation levels (Manual, Copy to Clipboard, Autofill, Full Automation) on the settings page. Each variant repeats the same 2x2 card grid with a different indicator strategy. Autofill (level 3) is shown as the active selection.

    1 Number Badge (current)

    Circular numbered badges in the top-right corner. Explicit ordering that communicates progression clearly, but adds visual clutter to each card.

    1
    Manual

    Codes are detected and shown. Nothing else happens automatically.

    2
    Copy to Clipboard

    The code is copied to the clipboard automatically when detected.

    3
    Autofill

    The code is filled into the input field on the page automatically.

    4
    Full Automation

    The code is filled in and the submit button is clicked automatically.

    2 No Indicator
