Design Decisions

    Shadow DOM Overlay

    A closed Shadow DOM overlay that tracks input fields and renders a shimmer border with inline status text. The overlay is appended to document.body, positioned with getBoundingClientRect(), and tracked via requestAnimationFrame.

    Fully isolated from host page CSS. Works across scroll, resize, transforms, and overflow clipping.

    State

    Try scrolling, resizing, or switching themes. The overlays track their target inputs in real time via requestAnimationFrame. The shimmer border uses @property --angle for smooth conic-gradient rotation with a static fallback for unsupported browsers.
