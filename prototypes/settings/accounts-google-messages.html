    Not connected

    SMS verification codes can be retrieved through Google Messages for Web. An Android device paired with Google Messages is required.

    How this works

    When a website asks for an SMS code, InboxKey opens Google Messages for Web in a background tab. It reads only the preview text of the last few messages, looking for a verification code. If a code is found, it is extracted and the tab is closed. If nothing is found within about 20 seconds, the tab is closed anyway. The tab is visible in the browser. Nothing is hidden.

    Why the phone number

    The phone number is stored only on this device, nowhere else. It helps InboxKey tell the difference between an SMS code and an email code. When a website shows hints like a country code, the last digits of a number, or words like "text message", InboxKey uses the phone number to recognize the field as SMS and check Google Messages. Without it, InboxKey would not know when to look.

    Good to know

    There is no API for Google Messages. This feature works by opening the website and reading the page, the same way a person would. The Google Messages session in the browser can expire over time. If it does, re-pair the device from messages.google.com. InboxKey will let you know when that happens.
