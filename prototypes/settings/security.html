    Privacy Practices

    How InboxKey protects your personal data

    100% Local Processing

    All email parsing and code extraction happens entirely on your device. No servers, no cloud, no remote processing.

    Zero Data Collection

    No tracking, no analytics, no telemetry. InboxKey does not phone home or communicate with any external services.

    Emails Stay on Device

    Your email content is accessed locally through the Gmail API or IMAP protocol, parsed in-memory, and never stored beyond the active session.

    Data Storage

    How your settings and credentials are stored

    Chrome Encrypted Storage

    All preferences and tokens are stored in Chrome's built-in encrypted storage, protected by your operating system's credentials manager.

    No Persistent Email Storage

    Verification codes are extracted in real-time and discarded after use. No email body content is ever written to disk.

    Minimal Data Footprint

    Only your account connection status, display preferences, and domain blacklist are stored locally. All data is deletable from the Settings tab.

    Encryption

    How credentials and tokens are secured

    OAuth 2.0 with PKCE

    Authentication uses industry-standard OAuth 2.0 with Proof Key for Code Exchange, preventing token interception attacks.

    OS-Level Credential Protection

    OAuth tokens are protected by your operating system's native credential store (Windows DPAPI, macOS Keychain, Linux Secret Service).

    TLS-Only Communication

    All API calls to Gmail and Outlook use TLS 1.2+ encryption. IMAP connections require SSL/STARTTLS.

    Permissions Audit

    Every permission explained with its exact purpose

    identity
    Sign in with your Google account to access Gmail API for reading verification emails.
    tabs
    Detect when you are on a login or verification page so InboxKey can offer to autofill codes.
    activeTab
    Access the current tab to find OTP input fields and insert verification codes when you click autofill.
    storage
    Save your preferences (theme, automation settings, domain blacklist) locally in Chrome's encrypted storage.
    scripting
    Inject the autofill chip into login pages to provide one-click code insertion into form fields.
    nativeMessaging
    Communicate with the local InboxBridge helper app for IMAP account support (optional, only if installed).
